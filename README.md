# Paradise Nursery

A React and Redux Toolkit shopping cart application for an online houseplant store.

## About the Project
Paradise Nursery lets users browse houseplants across different categories, see descriptions and prices, add plants to a shopping cart, and update quantities or remove items with live price totals.

## Features
- Landing page with company info and a Get Started button
- Product listing grouped into three plant categories (Air Purifying, Aromatic Fragrant, and Insect Repellent)
- Add to Cart buttons that disable once a plant is added and update the cart badge count in the navbar
- Shopping cart page with quantity increment/decrement controls, item removal, individual plant subtotals, and total cart cost
